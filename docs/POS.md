## POS 역할

### POS가 담당하는 업무
```
✓ 메뉴 주문 접수
✓ 보드게임 대여/반납 처리
✓ 추가 요금 계산 (분실, 파손)
✓ 당일 매출 확인
✓ 룸 상태 모니터링
```

### POS가 하지 않는 업무
```
✗ 룸 예약 (키오스크 담당)
✗ 시간권 결제 (키오스크 담당)
✗ 게임 등록/수정 (백오피스 담당)
✗ 메뉴 가격 설정 (백오피스 담당)
```

## POS 화면 구조

### 네비게이션
```
상단 메뉴바: [대시보드] [주문] [게임관리]
```

## 1. 대시보드

**책임**: 현재 매장 상황 모니터링

**포함 항목**:

1. 사용중인 룸 목록
   - 룸 번호
   - 입실 시간
   - 경과 시간
   - 시간 만료까지 남은 시간
   - 대여중인 게임 목록

2. 빠른 액션 버튼
   - 메뉴 주문 바로가기
   - 게임 대여 바로가기
   - 게임 반납 바로가기

3. 오늘의 매출 요약
   - 시간권 매출 (키오스크 집계)
   - 메뉴 매출 (POS 집계)
   - 총 매출

## 2. 주문 화면

**책임**: 메뉴 주문 처리 (태블릿 주문 알림 + 직접 주문)

**포함 항목**:

1. 실시간 주문 알림 영역 (최상단)
   - 태블릿에서 접수된 신규 주문 알림 팝업
     * 룸 번호
     * 주문 시간
     * 주문 내역 요약
     * 결제 방식 표시
       - PG 온라인 결제 완료
       - 현금/카드 결제 요청 (직원 처리 필요)
     * 알림음 재생
   - 알림 액션
     * [주문 확인] 버튼 → 주방 전송
     * [결제 처리] 버튼 (현금/카드 요청 시만 표시)
     * [주문 거절] 버튼 (품절 등)
   - 대기중인 주문 개수 표시

2. 룸 선택 영역 (좌측)
   - 현재 사용중인 룸 목록
   - 각 룸의 현재 상태 (사용중/비어있음)
   - 결제 대기중인 룸 표시 (배지)
   - 선택된 룸 하이라이트 표시

3. 메뉴 선택 영역 (중앙)
   - 메뉴 카테고리 탭
     * 음료
     * 간식
     * 기타
   - 각 메뉴 항목 표시
     * 메뉴 이름
     * 가격
     * 메뉴 이미지
   - 수량 선택 기능

4. 주문 내역 영역 (우측)
   - 현재 선택한 메뉴 목록
     * 메뉴명
     * 수량
     * 개별 금액
   - 총 주문 금액
   - 주문 전송 + 결제 처리 버튼
     * 현금 결제
     * 카드 결제
   - 주문 취소 버튼

5. 주문 및 결제 플로우
   - 카운터 직접 주문
     * 메뉴 선택
     * 즉시 현금/카드 결제
     * 주방 전송
   - 태블릿 PG 결제 주문
     * 알림 수신 (결제 완료 상태)
     * [주문 확인] 클릭 → 주방 전송
   - 태블릿 현금/카드 요청 주문
     * 알림 수신 (결제 대기 상태)
     * [결제 처리] 클릭 → 휴대용 단말기로 결제
     * 결제 완료 후 주방 전송

## 3. 게임 관리

### 3-1. 대여 화면

**책임**: 게임 대여 처리

**포함 항목**:

1. 게임 검색 영역 (상단)
   - 게임 이름 검색 입력창
   - 카테고리 필터 선택
     * 전체
     * 전략
     * 파티
     * 추리
     * 협력
     * 기타

2. 게임 목록 영역 (좌측)
   - 각 게임 카드 표시
     * 게임 썸네일 이미지
     * 게임 이름
     * 플레이 인원 (예: 2-4인)
     * 플레이 시간 (예: 30분)
     * 난이도 (쉬움/보통/어려움)
     * 게임 상태
       - 대여 가능 (초록색)
       - 대여중 (주황색) + 룸 번호 표시
       - 수리중 (빨간색) + 예상 수리 완료일
   - 페이지네이션 또는 무한 스크롤

3. 대여 처리 영역 (우측)
   - 선택된 게임 정보 표시
     * 게임 이름
     * 게임 이미지
     * 게임 설명
   - 대여 처리 입력
     * 룸 번호 선택 (드롭다운)
     * 대여 시간 자동 기록
   - 대여 처리 버튼
   - 취소 버튼

4. 추가 기능
   - 게임 상세 정보 보기
   - 대여 이력 조회

### 3-2. 반납 화면

**책임**: 게임 반납 처리

**포함 항목**:

1. 대여중인 게임 목록
   - 각 게임 정보
     * 게임 이름
     * 게임 이미지
     * 대여한 룸 번호
     * 대여 시간
     * 대여 경과 시간
   - 정렬 옵션
     * 대여 시간 순
     * 룸 번호 순
     * 게임 이름 순

2. 반납 처리 액션 (각 게임마다)
   - 정상 반납 버튼
   - 파손 신고 버튼
   - 분실 신고 버튼

3. 파손/분실 신고 팝업 (버튼 클릭 시)
   - 게임 이름 표시
   - 룸 번호 표시
   - 파손/분실 내역 입력창
     * 구체적인 파손 내용 (예: 카드 1장 찢어짐, 주사위 1개 분실)
   - 추가 요금 입력창
     * 수동 입력 또는 미리 설정된 금액 선택
   - 확인 버튼
   - 취소 버튼

4. 필터 기능
   - 특정 룸의 대여 게임만 보기
   - 대여 시간 필터 (1시간 이상, 2시간 이상 등)

## 시나리오별 사용법

### 시나리오 1: 태블릿 PG 결제 주문

```
상황: 401호에서 태블릿으로 아메리카노 2개 주문 + PG 결제 완료

POS 동작:
1. 화면 상단에 알림 팝업 표시
   "401호 - 새 주문 (아메리카노 x2) - PG 결제 완료"
2. 알림음 재생
3. 직원이 [주문 확인] 클릭
4. 자동으로 주방 프린터 출력

결과: 주문 접수 완료, 주방에서 조리 시작
```

### 시나리오 2: 태블릿 현금/카드 결제 요청

```
상황: 402호에서 태블릿으로 떡볶이 1개 주문 + 현금 결제 요청

POS 동작:
1. 화면 상단에 알림 팝업 표시
   "402호 - 새 주문 (떡볶이 x1) - 현금 결제 요청"
2. 알림음 재생
3. 직원이 402호로 이동
4. 휴대용 단말기로 현금 수령
5. POS에서 [결제 처리] 클릭
6. 결제 완료 → 주방 프린터 출력

결과: 결제 및 주문 접수 완료
```

### 시나리오 3: 카운터 직접 주문

```
상황: 손님이 카운터에서 현금으로 음료 구매

POS 조작:
1. [주문] 탭 클릭
2. 아메리카노 1개 선택
3. [현금 결제] 클릭
4. 금액 입력 → 거스름돈 계산
5. 결제 완료 → 주방 프린터 출력
6. [영수증 출력]

결과: 즉시 결제 및 주문 접수 완료
```

### 시나리오 4: 게임 대여

```
상황: 402호에 스플렌더 대여

POS 조작:
1. [게임관리] 탭 클릭
2. 검색바에 "스플렌더" 입력
3. 게임 선택
4. 룸 번호 "402" 입력
5. [대여 처리] 클릭

결과: 스플렌더 상태 "대여중(402호)"로 변경
```

### 시나리오 5: 게임 파손 처리

```
상황: 401호에서 카탄 반납, 주사위 1개 분실

POS 조작:
1. [게임관리] → 반납 탭
2. "카탄" 선택 (401호 대여중)
3. [파손 신고] 클릭
4. 파손 내역: "주사위 1개 분실"
5. 추가 요금: 5,000원 입력
6. 결제 방법 선택 (현금/카드)
7. [결제 처리] → 즉시 결제
8. [확인] 클릭

결과: 파손 요금 결제 완료, 카탄 "수리중" 상태로 변경
```
