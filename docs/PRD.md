# 보드게임 카페 POS 시스템 기획서

## 기획 개요

### 기획 배경
보드게임 카페는 일반 카페와 다르게 시간제 운영이 핵심입니다. 고객이 입장해서 시간을 구매하고, 그 시간 동안 게임을 즐기는 구조입니다. 하지만 현재 시장의 일반 POS는 이런 시간제 운영에 최적화되어 있지 않습니다.

### 해결하려는 문제
- 직원이 일일이 타이머를 확인하고 시간 연장을 관리해야 함
- 고객이 게임을 찾기 위해 직원을 계속 호출해야 함
- 여러 테이블의 시간을 동시에 관리하기 어려움
- 시간 초과 여부를 실시간으로 파악하기 힘듦

### 목표
보드게임 카페 운영에 최적화된 POS 시스템을 만들어, 점주는 효율적으로 매장을 관리하고 고객은 편리하게 게임을 즐길 수 있는 환경을 제공합니다.

---

## 서비스 구성

### 전체 구조

**관리자용 POS (데스크톱)**
- 점주와 직원이 사용
- 매장 전체를 한눈에 관리

**고객용 태블릿 (각 테이블)**
- 테이블마다 1대씩 배치
- 고객이 직접 게임을 검색하고 정보 확인

---

## 기술 스택

### UI/프론트엔드

| 기술             | 용도                               |
| ---------------- | ---------------------------------- |
| **Shadcn/ui**    | Radix UI 기반 Headless UI 컴포넌트 |
| **Tailwind CSS** | 유틸리티 기반 스타일링             |
| **Lucide React** | 아이콘 라이브러리                  |
| **Recharts**     | 차트 (매출/통계)                   |

### 플랫폼별 구현

| 플랫폼        | 해상도                      | 구현 방식                 |
| ------------- | --------------------------- | ------------------------- |
| 키오스크      | 1080×1920 (세로 고정)       | 웹 기반                   |
| 테이블 태블릿 | 1280×800 ~ 1920×1200 (가로) | 웹 → React Native WebView |
| 관리자 POS    | 1280×720 ~ 1920×1080+       | 데스크톱 웹               |

### Shadcn/ui 선택 이유

1. **접근성**: Radix UI 기반으로 WCAG 자동 준수
2. **커스터마이징**: 컴포넌트 소스 직접 소유
3. **터치 최적화**: 모바일/태블릿 터치 인터랙션 우수
4. **WebView 호환**: React Native WebView에서 문제없이 동작

## 핵심 기능

### POS - 테이블 실시간 모니터링

**문제 상황**
지금은 점주가 각 테이블의 시간을 일일이 확인해야 합니다. 테이블이 10개만 되어도 누가 몇 분 남았는지 헷갈립니다.

**해결 방안**
화면에 매장의 모든 테이블이 한눈에 보입니다. 각 테이블마다 다음 정보가 표시됩니다.

- 테이블 번호
- 현재 상태 (빈 테이블 / 사용 중)
- 입실 시간
- 남은 시간
- 지금까지 사용 금액

**상태별 색상**
- 회색: 빈 테이블
- 파란색: 이용 중 (시간 충분)
- 노란색: 10분 이하 남음
- 빨간색: 시간 초과

이렇게 하면 점주는 화면만 보고도 어느 테이블에 가서 시간 연장을 안내해야 할지 바로 알 수 있습니다.

---

### POS - 결제 내역 확인

> **MVP 단계**: 실제 결제 연동 없이 결제 완료 처리만 시뮬레이션합니다.

**결제 방식: 선결제**
- 고객이 키오스크에서 시간 선택 후 결제
- 연장 시 태블릿에서 추가 결제
- 퇴장 시 추가 결제 없음 (이미 선결제 완료)
- 잔여 시간 적립/이월 없음

**POS에서 확인 가능한 정보**
- 각 테이블별 결제 내역
- 입장 결제 금액
- 연장 결제 금액
- 총 결제 금액

---

### POS - 게임 관리

**등록할 정보**
- 게임 이름
- 게임 사진
- 몇 명이서 하는지 (2~4인 등)
- 게임 시간 (30분, 60분 등)
- 어려운 정도 (쉬움, 보통, 어려움)
- 게임 종류 (전략, 파티, 추리 등)
- 게임 설명
- 매장 추천 게임 표시

**재고 관리**
- 같은 게임 몇 개 있는지
- 지금 대여 가능한지
- 분실이나 파손 체크

**인기도 확인**
- 어떤 게임이 인기 있는지
- 게임별로 몇 번 대여됐는지
- 장르별 선호도

---

### POS - 매출 관리

**오늘 매출 한눈에**
- 지금까지 얼마 벌었는지
- 현금/카드 각각 얼마인지
- 시간대별로 언제 손님이 많았는지

**기간별 비교**
- 이번 달 vs 지난달
- 올해 vs 작년
- 요일별 매출 차이

**게임 통계**
- 인기 게임 순위
- 어떤 장르를 좋아하는지
- 안 대여되는 게임은 뭔지

**운영 지표**
- 테이블 회전율 (하루에 한 테이블을 몇 팀이 쓰는지)
- 평균 체류 시간
- 시간대별 방문 고객 수

**데이터 내보내기**
- 엑셀 파일로 저장
- 세무사에게 전달용

---

### POS - 매장 설정

**기본 정보 입력**
- 매장 이름, 주소, 전화번호
- 영업 시간
- 매장 소개 글

**요금 설정**
- 평일 요금
- 주말 요금

**테이블(방) 설정**
- 테이블 몇 개인지
- 각 테이블 번호
- 권장 인원 (최소~최대)
  - 예: 1번 방 - 2~4인 권장
  - 예: 2번 방 - 4~6인 권장
  - 예: 3번 방 - 6~8인 권장
- 방 크기/특성 메모 (선택사항)

**영업일 관리**
- 정기 휴무일 (매주 월요일 등)
- 임시 휴무일 (명절 등)

---

### 태블릿 - 매장 소개

**첫 화면에 보이는 것**
- 매장 소개 영상
- 매장 특징
- 영업 시간
- 위치

고객이 처음 와도 우리 매장이 어떤 곳인지 바로 알 수 있습니다.

---

### 태블릿 - 이용 안내

**설명할 내용**
- 게임 검색하는 방법
- 시간 연장하는 방법
- 직원 부르는 방법
- 결제하는 방법

그림과 설명을 같이 보여줘서 누구나 쉽게 이해할 수 있게 합니다.

---

### 태블릿 - 시간 알림 및 연장 결제

**시간 알림 시스템**
- 10분 전: "이용 시간이 10분 남았습니다" 팝업 알림
- 시간 종료: "이용 시간이 종료되었습니다" 팝업 알림
- 알림 시 연장 옵션 바로 제공

**연장 결제 (MVP - 하드코딩)**

> **MVP 단계**: 키오스크, 태블릿 모두 실제 결제 연동 없이 결제 완료 처리만 시뮬레이션합니다.

- 지원 결제 방법 (UI만 제공):
  - 카카오페이
  - 네이버페이
  - 신용카드/체크카드
- 결제 방법 선택 시 즉시 "결제 완료" 상태로 전환
- 결제 완료 즉시 시간 자동 연장
- POS에도 실시간 반영

---

### 태블릿 - 게임 검색 (핵심 기능)

**문제 상황**
고객이 게임을 찾으려면 직원을 불러야 합니다. 직원도 모든 게임을 다 알 수 없습니다. 게임 찾는데만 시간이 오래 걸립니다.

**해결 방안**

**검색 방법**
- 게임 이름으로 검색
- 자동 완성으로 편하게

**필터 기능**
- 몇 명이서 할 건지 (2인용, 3인용, 4인 이상 등)
- 어떤 종류 원하는지 (전략, 파티, 추리 등)
- 난이도 (쉬운 거, 어려운 거)
- 매장 추천 게임만 보기

**게임 정보 화면**
- 큰 게임 사진
- 게임 이름
- 몇 명이 하는지
- 얼마나 걸리는지
- 어렵기는 어떤지
- 게임 설명
- 어떻게 하는지 (룰 설명)

**추가 기능**
- 지금 대여 가능한지 바로 표시
- 게임 설명 들으려면 직원 호출 버튼

이제 고객은 태블릿으로 직접 게임을 찾고, 마음에 드는 게임을 골라서 직원에게 가져다 달라고 할 수 있습니다.

## 기대 효과

### 점주 입장

**인건비 절감**
- 고객이 태블릿으로 직접 게임 검색
- 직원이 게임 설명하러 다닐 필요 없음
- 최소 인력으로 운영 가능

**운영 효율 향상**
- 모든 테이블 상태를 한눈에 파악
- 시간 계산 자동화로 실수 없음
- 결제 처리 빨라짐

**데이터 기반 운영**
- 어떤 게임이 인기 있는지 파악
- 매출 패턴 분석
- 재고 관리 효율화

### 고객 입장

**편리한 이용**
- 직원 안 불러도 게임 정보 확인
- 원하는 게임 빨리 찾기
- 대기 시간 감소

**투명한 요금**
- 남은 시간 실시간 확인
- 선결제로 추가 요금 걱정 없음

- 추천 방과 다른 방을 분리해서 선택 부담 줄임
- 방 상태(빈 방/사용 중)가 색상으로 한눈에 보임
- 가장 인기 있는 2시간 옵션에 "추천" 뱃지
- "연장 가능"하다는 안내로 결정 부담 줄임
- 결제 완료 후 방 번호와 종료 시각 크게 표시
- 5초 카운트다운으로 다음 고객 대비

### UX 핵심 원칙

**1. 4탭 룰**
- 모든 주요 액션은 4번의 터치 이내에 완료
- 인원 선택 → 방 선택 → 시간 선택 → 결제 완료

**2. 선결제 시스템**
- 입장 시 결제를 완료해서 퇴장 시 대기 시간 제거
- 연장도 테이블에서 바로 결제

**3. 시각적 명확성**
- 방 상태: 초록색(빈 방), 빨간색(사용 중)
- 시간 상태: 파란색(여유), 노란색(10분 이하), 빨간색(초과)
- 추천 옵션에 뱃지 표시

**4. 불안 제거**
- "시간 연장 가능" 안내로 결정 부담 감소
- 종료 시각 명확히 표시
- 10분 전 미리 알림

**5. 무인화 최적화**
- 직원 도움 없이 입장부터 퇴장까지 가능
- 문의 필요 시 직원 호출 버튼 제공

## 운영 시나리오 (점주 관점)

### 고객 입장부터 퇴장까지

**1. 고객 입장**
- 점주가 빈 테이블 클릭
- 입실 버튼 클릭
- 자동으로 시간 측정 시작

**2. 게임 선택**
- 고객이 테이블 태블릿으로 게임 검색
- 마음에 드는 게임 선택
- 직원 호출해서 게임 요청
- 직원이 게임 가져다줌

**3. 시간 연장 (필요시)**
- 시간이 10분 남으면 노란색 표시
- 점주가 테이블 가서 연장 안내
- POS에서 시간 연장 클릭

**4. 퇴실**
- 고객이 태블릿에서 퇴장 버튼 클릭
- POS에서 해당 테이블 퇴실 상태로 변경
- 선결제 완료 상태이므로 추가 결제 없음

### 게임 재고 관리

**새 게임 입고**
- 게임 관리 메뉴
- 새 게임 등록
- 정보 입력 및 사진 업로드
- 저장

**게임 분실/파손**
- 해당 게임 선택
- 상태 변경 (분실/파손)
- 대여 불가능으로 자동 전환

### 일일 정산

**영업 종료 후**
- 통계 메뉴 클릭
- 오늘 매출 확인
- 결제 수단별 금액 확인
- 현금 시재 확인
- 정산 완료

### 타 플랫폼과의 유사점

기존 보드게임 카페용 솔루션들을 벤치마킹하되, 더 직관적이고 사용하기 쉽게 만듭니다.

**공통점**
- POS와 태블릿 연동
- 시간제 자동 계산
- 게임 검색 기능

**개선점**
- 더 간단한 UI/UX
- 빠른 속도
- 합리적인 가격

## 예상 질문 (FAQ)

**Q1. 태블릿은 매장에서 구매해야 하나요?**
A. 네, 일반 안드로이드 태블릿을 테이블 수만큼 준비하시면 됩니다.

**Q2. 인터넷이 끊기면 어떻게 되나요?**
A. 기본적인 시간 측정과 계산은 로컬에서 작동합니다. 인터넷 복구 후 자동으로 동기화됩니다.

**Q3. 기존에 쓰던 POS가 있는데 교체해야 하나요?**
A. 우리 시스템은 별도 프로그램이라 기존 POS와 함께 사용 가능합니다.

**Q4. 직원 교육은 얼마나 걸리나요?**
A. 기본 사용법은 30분 정도면 충분합니다. 상세 매뉴얼도 제공합니다.

**Q5. 게임이 많으면 등록이 힘들지 않나요?**
A. 엑셀로 일괄 업로드 기능을 제공합니다.
