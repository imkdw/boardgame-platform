## 기술 스택

### UI 컴포넌트 라이브러리

| 기술             | 용도                               |
| ---------------- | ---------------------------------- |
| **Shadcn/ui**    | Radix UI 기반 Headless UI 컴포넌트 |
| **Tailwind CSS** | 유틸리티 기반 스타일링             |
| **Lucide React** | 아이콘 라이브러리                  |
| **Recharts**     | 차트 라이브러리 (매출/통계용)      |
| **Sonner**       | 토스트 알림 (Shadcn/ui 연동)       |

### Shadcn/ui 선택 이유

1. **Headless UI 기반**: Radix UI의 WCAG 접근성 자동 준수
2. **완전한 커스터마이징**: 컴포넌트 소스 직접 소유
3. **Tailwind 통합**: 디자인 토큰 적용 용이
4. **터치 최적화**: 모바일/태블릿 터치 인터랙션 우수
5. **WebView 호환**: React Native WebView에서 문제없이 동작

### 플랫폼별 구현 방식

**키오스크**

- 세로(Portrait) 모드 전용 (1080×1920)
- 웹 기반, 키오스크 전용 브라우저 구동
- 터치 타겟 최소 48px

**테이블 태블릿**

- 웹(Web) 기반 UI 개발
- React Native WebView로 앱 형태 제공
- CSS 애니메이션 최적화 (WebView 성능)
- 가로(Landscape) 모드 기준

**관리자 POS**

- 데스크톱 웹 브라우저 구동
- 마우스/키보드 인터랙션 최적화
- 터치스크린 지원 (선택사항)

### 다국어 지원

| 한국어 | `ko` | 키오스크, 태블릿 |
| 영어   | `en` | 키오스크, 태블릿 |
| 일본어 | `ja` | 키오스크, 태블릿 |

**언어 선택 UI**

- 키오스크: 대기 화면(K-1)에 언어 선택 버튼 배치
- 태블릿: 상단 헤더 또는 설정에서 언어 변경 가능
- 기본 언어: 한국어 (`ko`)

**관리자 POS**

- 다국어 미지원 (한국어 고정)

**손님용 (키오스크, 태블릿)**

- 테이블/카드 뷰 혼합 레이아웃
- 효율성 중심 설계

## 키오스크 (입구)

> 핵심 원칙: 4번의 터치 이내에 입장 완료

### K-1. 대기 화면 (Idle Screen)

**목적**: 고객 유입 유도, 매장 브랜딩

**필수 요소**

- 매장 로고 및 이름
- 환영 메시지 ("어서오세요!" 등)
- 터치하여 시작 유도 문구/애니메이션
- 현재 시간 표시
- 배경 이미지 또는 영상 (매장 분위기)
- **언어 선택 버튼** (우상단 또는 하단)
  - 🇰🇷 한국어 / 🇺🇸 English / 🇯🇵 日本語
  - 국기 아이콘 + 언어명 조합

**인터랙션**

- 화면 아무 곳이나 터치 시 인원 선택 화면으로 전환
- 언어 버튼 터치 시 해당 언어로 전환 (전체 플로우에 적용)
- 일정 시간(30초) 동안 미사용 시 화면 보호기 또는 프로모션 슬라이드

**디자인 노트**

- 대형 폰트 사용 (접근성)
- 부드러운 애니메이션으로 시선 유도
- 매장 컬러 테마 적용

---

### K-2. 인원 선택 화면

**목적**: 방문 인원 수 파악

**필수 요소**

- 헤더: 질문 문구 ("몇 분이서 오셨나요?")
- 인원 선택 버튼 그룹
  - 2명, 3명, 4명, 5명, 6명, 7명, 8명 이상
  - 각 버튼은 충분한 크기와 간격
- 뒤로가기 버튼 (대기 화면으로)

**인터랙션**

- 인원 버튼 터치 시 선택 상태 시각적 표시
- 선택 즉시 방 선택 화면으로 자동 전환 (또는 확인 버튼)
- 버튼 터치 시 햅틱/사운드 피드백

**디자인 노트**

- 버튼은 그리드 형태로 균등 배치
- 선택된 버튼은 색상 변화 및 체크 아이콘
- 8명 이상은 별도 입력 모달 또는 직원 호출 안내

---

### K-3. 방 선택 화면

**목적**: 인원에 적합한 방 배정

**필수 요소**

- 상단 정보 바
  - 선택된 인원 수 표시
  - 인원 변경 버튼
- 추천 방 섹션
  - "추천" 뱃지가 달린 방 카드들
  - 선택 인원에 최적화된 방 우선 표시
- 기타 방 섹션 (접기/펼치기 가능)
  - 추천 외 다른 방들
- 각 방 카드 정보
  - 방 번호/이름
  - 권장 인원 (예: 2~4인)
  - 현재 상태 (빈 방/이용 중)
  - 방 특성 설명 (선택사항)
- 뒤로가기 버튼

**상태별 스타일링**

- 빈 방: 선택 가능, 밝은 색상, 터치 가능
- 이용 중: 비활성화, 회색 처리, 터치 불가
- 추천 방: 강조 테두리 또는 뱃지

**인터랙션**

- 빈 방 터치 시 선택 상태로 변경
- 선택 후 시간 선택 화면으로 전환
- 이용 중인 방은 터치해도 반응 없음 (또는 툴팁)

**디자인 노트**

- 카드형 레이아웃 (그리드)
- 상태에 따른 색상 코드 명확히 구분
- 스크롤 가능한 영역 (방이 많을 경우)

---

### K-4. 시간 선택 화면

**목적**: 이용 시간 결정

**필수 요소**

- 상단 정보 바
  - 선택된 방 정보 (방 번호, 권장 인원)
  - 선택된 인원 수
  - 뒤로가기 버튼
- 시간 옵션 카드들
  - 각 옵션별 정보
    - 이용 시간 (1시간, 2시간, 3시간, 무제한 등)
    - 요금 (평일/주말 자동 적용)
    - 추천 뱃지 (가장 인기 있는 옵션)
- 안내 문구
  - "시간이 부족하면 나중에 연장할 수 있어요!"

**인터랙션**

- 시간 옵션 터치 시 선택 상태 표시
- 선택 후 결제 화면으로 전환
- 각 옵션 호버/터치 시 미세한 확대 효과

**디자인 노트**

- 세로 리스트 형태로 배치
- 추천 옵션은 시각적으로 강조 (테두리, 뱃지, 크기)
- 요금은 큰 폰트로 명확하게

---

### K-5. 결제 화면

**목적**: 최종 확인 및 결제 진행

**필수 요소**

- 이용 내역 요약 카드
  - 방 정보 (번호, 권장 인원)
  - 이용 시간
  - 인원 수
  - 총 결제 금액 (강조)
- 결제 수단 선택 영역
  - 카드 결제
  - 현금 결제
  - 카카오페이
  - 네이버페이
  - (추후 확장 가능한 구조)
- 결제 진행 버튼
  - "결제하고 입장하기"
- 뒤로가기 버튼
- 전체 취소 버튼

**인터랙션**

- 결제 수단 선택 시 시각적 표시
- 결제 버튼 터치 시 로딩 상태 표시
- MVP: 결제 버튼 터치 시 즉시 결제 완료 처리 (시뮬레이션)

**디자인 노트**

- 결제 금액은 가장 크고 눈에 띄게
- 결제 수단 아이콘은 브랜드 로고 사용
- 결제 버튼은 CTA 색상으로 강조

---

### K-6. 결제 완료 / 입장 안내 화면

**목적**: 결제 확인 및 방 안내

**필수 요소**

- 완료 메시지 ("결제가 완료되었습니다!")
- 배정된 방 정보 카드 (크게 강조)
  - 방 번호 (매우 큰 폰트)
  - 이용 시간
  - 종료 예정 시각
- 안내 메시지
  - "X번 방으로 이동해주세요!"
  - "테이블의 태블릿에서 게임을 검색할 수 있어요"
- 자동 전환 카운트다운 (5초)

**인터랙션**

- 5초 후 자동으로 대기 화면으로 전환
- 화면 터치 시 즉시 대기 화면으로 전환 가능

**디자인 노트**

- 성공/완료 느낌의 색상 (녹색 계열)
- 방 번호는 화면에서 가장 크게
- 체크 아이콘 또는 성공 애니메이션

- 매장 특징/컨셉 설명
- 영업 정보
  - 영업 시간
  - 휴무일
  - 주소/위치
  - 연락처

**디자인 노트**

- 비주얼 중심의 레이아웃
- 스크롤 가능한 단일 페이지
- 매장 분위기를 느낄 수 있는 이미지 활용

### T-2. 이용 안내 탭

**필수 요소**

- 단계별 이용 가이드 (카드 또는 캐러셀 형태)
  - 게임 검색하는 방법
  - 게임 대여 요청하는 방법
  - 시간 연장하는 방법
  - 직원 부르는 방법
  - 퇴장하는 방법
- 각 단계별 설명
  - 아이콘 또는 일러스트
  - 간단한 텍스트 설명
  - 화면 예시 이미지 (선택사항)
- 자주 묻는 질문 (FAQ) 섹션

**디자인 노트**

- 그림 + 텍스트 조합으로 쉽게 이해
- 스텝 인디케이터로 진행 상황 표시
- 스와이프로 다음 단계 이동

### T-3. 게임 검색 탭 (메인)

**목적**: 게임 탐색 및 검색

**필수 요소**

- 검색 영역
  - 검색 입력창 (자동완성 지원)
  - 검색 아이콘
- 필터 영역
  - 인원수 필터 (2인, 3인, 4인, 5인 이상 등)
  - 장르 필터 (전략, 파티, 추리, 협동 등)
  - 난이도 필터 (쉬움, 보통, 어려움)
  - 플레이 시간 필터 (30분 이하, 30~60분, 60분 이상)
  - 대여 가능 여부 필터
  - 매장 추천 게임 필터
  - 필터 초기화 버튼
- 정렬 옵션
  - 추천순
  - 인기순
  - 이름순
  - 난이도순
- 게임 목록 영역
  - 게임 카드 그리드
  - 무한 스크롤 또는 페이지네이션
  - 검색 결과 수 표시
- 빈 상태 표시
  - 검색 결과 없음 시 안내 메시지
  - 필터 조건 완화 제안

**게임 카드 요소**

- 게임 썸네일 이미지
- 게임 이름
- 인원수 아이콘 (예: 2~4인)
- 플레이 시간 아이콘
- 난이도 표시 (별점 또는 텍스트)
- 장르 태그
- 대여 가능 여부 뱃지
- 매장 추천 뱃지 (해당 시)

**인터랙션**

### P-1. 테이블 관리 (대시보드) 화면

**목적**: 매장 전체 테이블 실시간 모니터링

**필수 요소**

- 요약 통계 바
  - 총 테이블 수
  - 사용 중 테이블 수
  - 빈 테이블 수
  - 시간 임박/초과 테이블 수
- 테이블 그리드 영역 (좌측 또는 메인)
  - 테이블 카드들 (실제 매장 배치와 유사하게)
  - 각 테이블 카드 정보
    - 테이블 번호
    - 현재 상태 아이콘
    - 입실 시간
    - 남은 시간 (실시간)
    - 인원수
    - 누적 금액
  - 상태별 색상 구분
    - 회색: 빈 테이블
    - 파란색/녹색: 이용 중 (시간 충분)
    - 노란색: 10분 이하 남음
    - 빨간색: 시간 초과
- 선택된 테이블 상세 패널 (우측)
  - 테이블 상세 정보
  - 액션 버튼들 (입실, 퇴실, 시간 연장 등)

**인터랙션**

- 테이블 카드 클릭 시 상세 패널에 정보 표시
- 상태별 필터링 (전체/빈 테이블/사용 중/주의 필요)
- 실시간 자동 업데이트 (WebSocket)

**디자인 노트**

- 테이블 배치는 드래그로 커스터마이징 가능 (설정에서)
- 상태 변화 시 부드러운 애니메이션
- 시간 초과 테이블은 깜빡임 효과

  - 카드/현금/카카오페이/네이버페이

- 카드형 레이아웃으로 지표 그룹핑
- 차트는 인터랙티브 (호버 시 상세 값)
- 이전 기간 대비 증감 표시 (화살표, 퍼센트)

### P-10. 매출/통계 - 상세 분석 화면

**목적**: 심층 데이터 분석

**필수 요소**

- 기간별 매출 비교
  - 이번 달 vs 지난달
  - 올해 vs 작년
  - 요일별 매출 패턴
- 시간대별 분석
  - 피크 타임 파악
  - 시간대별 방문 고객 수
- 게임 통계
  - 인기 게임 순위 (대여 횟수 기준)
  - 장르별 선호도
  - 사용되지 않는 게임 목록
- 데이터 내보내기
  - 엑셀 다운로드 버튼
  - 기간 및 항목 선택

    - 시간별 요금

  - 1시간 연장 금액

  - 단체 할인 설정

  - 테이블 번호/이름
  - 최소 인원
  - 최대 인원
  - 메모 (선택사항)

### 공통 컴포넌트

| 화면 요소    | Shadcn/ui 컴포넌트       | 용도                                |
| ------------ | ------------------------ | ----------------------------------- |
| 버튼         | `Button`                 | 모든 액션 버튼                      |
| 카드         | `Card`                   | 정보 그룹핑, 테이블 카드, 게임 카드 |
| 모달/팝업    | `Dialog`                 | 확인창, 입력 폼, 알림               |
| 바텀시트     | `Sheet`                  | 모바일/태블릿 하단 모달             |
| 토스트 알림  | `Sonner`                 | 성공/에러/경고 피드백               |
| 입력 필드    | `Input`                  | 텍스트 입력                         |
| 셀렉트박스   | `Select`                 | 드롭다운 선택                       |
| 체크박스     | `Checkbox`               | 다중 선택                           |
| 라디오       | `RadioGroup`             | 단일 선택                           |
| 스위치       | `Switch`                 | 토글 on/off                         |
| 탭           | `Tabs`                   | 화면 내 탭 전환                     |
| 뱃지         | `Badge`                  | 상태 표시, 태그                     |
| 스켈레톤     | `Skeleton`               | 로딩 상태                           |
| 프로그레스   | `Progress`               | 진행률 표시                         |
| 툴팁         | `Tooltip`                | 추가 설명                           |
| 드롭다운     | `DropdownMenu`           | 메뉴, 옵션 선택                     |

| 폼           | `Form` (react-hook-form) | 폼 검증                             |
| 캘린더       | `Calendar` + `Popover`   | 날짜 선택                           |
| 캐러셀       | `Carousel`               | 이미지 슬라이더                     |
| 아코디언     | `Accordion`              | 접기/펼치기 콘텐츠                  |
| 알림창       | `Alert`                  | 중요 안내 메시지                    |
| 명령 팔레트  | `Command`                | 검색/자동완성                       |
| 페이지네이션 | `Pagination`             | 페이지 이동                         |

### 버튼 Variant 매핑

| Variant       | 용도                         | 디자인 토큰                   |
| ------------- | ---------------------------- | ----------------------------- |
| `default`     | 주요 액션 (결제, 저장, 확인) | `boardgame-primary` (#7c27f2) |
| `secondary`   | 보조 액션 (취소, 뒤로가기)   | `btn-gray` (#f6f6f6)          |
| `destructive` | 위험 액션 (삭제, 퇴장)       | `status-error` (#e22a00)      |
| `outline`     | 테두리만 있는 버튼           | border only                   |
| `ghost`       | 배경 없는 텍스트 버튼        | transparent                   |
| `link`        | 링크 스타일 버튼             | underline                     |

### 플랫폼별 추가 컴포넌트

**키오스크 전용**

- 대형 터치 버튼 (Button 커스텀, 최소 80px)

- 카운트다운 타이머 (커스텀)

**태블릿 전용**

- 게임 카드 그리드 (Card 기반)
- 필터 칩 (Badge/Toggle 조합)
- 시간 프로그레스 링 (커스텀)

**POS 전용**

- 데이터 테이블 (Table + 정렬/필터)
- 차트 (Recharts 연동)
- 사이드바 네비게이션 (커스텀)
- 통계 카드 (Card 기반)

## 공통 컴포넌트

### 상태 색상 체계

| 상태    | 색상 토큰         | HEX     | 용도               |
| ------- | ----------------- | ------- | ------------------ |
| 빈 상태 | `status-default`  | #ebecf0 | 빈 테이블, 비활성  |
| 정상    | `status-progress` | #0065ff | 이용 중, 정상 상태 |
| 주의    | `status-warning`  | #ffab00 | 10분 이하, 경고    |
| 위험    | `status-error`    | #e22a00 | 시간 초과, 에러    |
| 성공    | `status-complete` | #36b37e | 완료, 성공         |

### 로딩 상태

| 상황        | Shadcn/ui 컴포넌트 | 설명            |
| ----------- | ------------------ | --------------- |
| API 호출    | 스피너 (커스텀)    | 짧은 로딩       |
| 콘텐츠 로딩 | `Skeleton`         | 목록, 카드 로딩 |
| 업로드 진행 | `Progress`         | 진행률 표시     |

### 빈 상태 (Empty State)

- Lucide 아이콘 사용
- 상황 설명 메시지
- 액션 유도 버튼 (`Button`)

### 에러 상태

- `Alert` 컴포넌트 (variant="destructive")
- 에러 아이콘 (Lucide)
- 재시도 버튼

### 토스트 알림 (Sonner)

| 유형 | 색상              | 아이콘        |
| ---- | ----------------- | ------------- |
| 성공 | `status-complete` | Check         |
| 에러 | `status-error`    | X             |
| 경고 | `status-warning`  | AlertTriangle |
| 정보 | `status-progress` | Info          |

- 자동 사라짐: 3~5초
- 수동 닫기 가능

### 모달 구조 (Dialog)

- 배경 딤 처리 (자동)
- 중앙 정렬
- `DialogHeader`: 제목
- `DialogContent`: 본문
- `DialogFooter`: 액션 버튼들
- ESC 키 또는 외부 클릭으로 닫기

### 입력 필드 (Input + Form)

- `Label`: 라벨
- `Input`: 입력창
- `FormDescription`: 헬퍼 텍스트
- `FormMessage`: 에러 메시지
- 필수 필드 표시 (\*)

## 반응형 고려사항

### 키오스크

- 고정 해상도 (1080x1920 세로 또는 1920x1080 가로)
- 터치 최적화 (대형 터치 타겟)

### 태블릿

- 태블릿 가로 모드 기준 (1280x800 ~ 1920x1200)
- 터치 최적화

### POS (데스크톱)

- 최소 1280x720
- 권장 1920x1080 이상
- 마우스/키보드 최적화
- 터치 지원 (선택사항)

- 충분한 색상 대비 (WCAG AA 이상)
- 키보드 네비게이션 지원 (POS)
- 터치 타겟 최소 48x48px
- 의미 있는 대체 텍스트 (이미지)
- 명확한 포커스 표시
- 에러 메시지 명확한 안내
