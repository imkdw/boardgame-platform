# 보드게임 플랫폼 디자인 컨셉

## 타겟층
10-20대 학생 및 성인

---

## 기술 스택

### UI 컴포넌트 라이브러리
- **Shadcn/ui**: Radix UI + Tailwind CSS 기반의 컴포넌트 라이브러리
- 복사해서 사용하는 방식으로 완전한 커스터마이징 가능
- Headless UI(Radix) 기반으로 접근성(WCAG) 자동 준수

### 스타일링
- **Tailwind CSS**: 유틸리티 기반 CSS 프레임워크
- CSS 변수를 통한 디자인 토큰 관리
- 반응형 디자인 지원

### 아이콘
- **Lucide React**: 경량화된 아이콘 라이브러리
- Shadcn/ui와 기본 연동

### Shadcn/ui 선택 이유
1. **Headless UI 기반**: Radix UI의 접근성 자동 준수
2. **완전한 커스터마이징**: 컴포넌트 소스를 직접 소유하여 자유로운 수정
3. **Tailwind 통합**: 디자인 토큰 적용 용이
4. **터치 최적화**: 모바일/태블릿 터치 인터랙션 우수
5. **WebView 호환**: React Native WebView에서 문제없이 동작

## 손님용 (사용자 측면)

### 디자인 방향
- 모던/미니멀 기반
- 깔끔하고 세련된 느낌
- 기능 중심의 직관적인 구조

### 핵심 의도
- 친근함: 처음 접하는 사람도 쉽게 이해 가능
- 접근성: 복잡한 UI 배제, 편하게 플레이에 집중
- 직관성: 설명 없이도 사용 가능한 인터페이스

### 감정적 목표
- 쉽고 빠르게 접근 가능한 플랫폼
- 복잡한 게이밍 UI가 아닌 캐주얼한 느낌
- 즐거움 중심, 경쟁보다는 재미 강조

## 관리자용 (운영 측면)

### 디자인 방향
- 대시보드 중심 설계
- 정보 밀도 높은 레이아웃
- 기능 우선, 효율성 중심

### 핵심 기능
- 모니터링: 실시간 게임 현황, 동접자, 문제 상황 파악
- 관리: 유저 제재, 방 관리, 신고 처리
- 분석: 통계, 매출, 사용자 행동 패턴

### 설계 원칙
- 한 눈에 많은 정보 파악 가능
- 최소 클릭으로 작업 완료
- 실시간 업데이트 (WebSocket)
- 테이블 뷰 중심의 데이터 표시

## 요약
- 손님용: 미니멀하고 쉬운 UI
- 관리자용: 정보 밀도 높고 기능적인 대시보드
- 두 시스템은 완전히 분리된 별도 접근
- **모든 UI는 Shadcn/ui + Tailwind CSS 기반으로 구현**
